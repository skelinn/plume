Method

Each run samples the true vehicle and environment from the dispersion file; the flight software flies with the nominal vehicle, the forecast environment and the pre-flight ascent plan. Success probability uses the Wilson score interval. Ellipses assume a bivariate normal landing distribution. These are simulation results: model-form error is not included beyond the dispersed parameters (see docs/models).
